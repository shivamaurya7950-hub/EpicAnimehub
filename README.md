# EpicAnimehub - Anime World

**Anime World** is a mobile-friendly Netflix-style website featuring **46 anime posters**, organized by categories like **Action, Fantasy, Romance, Comedy**, and more.  

This website includes:  
- ✅ Working **search bar** to filter anime  
- ✅ **Episode buttons** for each anime  
- ✅ **Scroll-friendly Netflix-style grid layout**  
- ✅ Mobile-friendly design
